# Histórico de atualizações

O SEGARK EDR ainda não tem versão estável. Durante o beta, as notas de cada versão são entregues diretamente aos parceiros do programa de acesso antecipado.

Este histórico começa na primeira versão estável. Cada entrada traz:

- **Novidades**
- **Correções**
- **Mudanças incompatíveis**, com o que fazer antes de atualizar

O roadmap fica na página [Versões](https://www.segark.com/releases#edr) do site.
