# Agente Windows

:::note[Em desenvolvimento]
O agente Windows ainda não tem versão publicada. Esta página será preenchida com a instalação quando a primeira versão sair.
:::

O que já existe e foi provado em laboratório, em modo usuário:

- telemetria por ETW;
- inspeção de scripts via AMSI;
- varredura de arquivos e quarentena;
- isolamento de rede pelo Firewall do Windows.

Testado em Windows 11 e Windows Server 2022. A proteção em kernel ainda não está disponível. Somente x64.
