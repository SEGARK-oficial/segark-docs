# Live Query

Live Query (no console, **Live Discover**) pergunta aos hosts como eles estão agora: processos, portas abertas, usuários, pacotes, tarefas agendadas e outras tabelas.

- Disponível para o papel de analista e acima.
- Até 500 dispositivos por execução.
- Comece pelas consultas prontas e ajuste para o seu caso.

Exemplos de uso no dia a dia:

- encontrar todos os servidores com uma porta inesperada escutando;
- listar onde um pacote vulnerável está instalado;
- conferir quem tem chave SSH autorizada em servidores críticos.
